# ربات و مینی‌اپ فروشگاهی تلگرام

فروش محصولات دیجیتال در تلگرام؛ با مینی‌اپ فارسی، پنل مدیریت، پرداخت و تحویل خودکار. هر نصب، یک فروشگاه مستقل با ربات اختصاصی است.

**[دموی تعاملی و معرفی کامل](https://amirmalek.ir/telegram-marketplace-miniapp/)** · **[نصب و معماری — فارسی](docs/INSTALLATION.fa.md)** · **[Installation & architecture — English](docs/INSTALLATION.en.md)**

## امکانات اصلی

- تحویل فایل، پیام، اطلاعات موجودی، باندل یا نتیجه API.
- پرداخت Stars، کارت‌به‌کارت با تأیید مدیر و کیف پول داخلی.
- اشتراک VIP، کد تخفیف، دعوت دوستان و اعلان‌های همگانی.
- سفارش‌ها، دسترسی به خریدها و پشتیبانی تیکتی.
- ویرایش زنده متن‌ها، رنگ‌ها، ویجت‌ها، سربرگ و منوی مینی‌اپ.
